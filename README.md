# 🤐 Анонимный Чат Бот

Telegram-бот, который позволяет общаться в группе анонимно. Вы пишете боту в личные сообщения, а он публикует ваши сообщения в общем чате без вашего имени.

---

## Как это работает

**В три простых шага:**

1. Вы находите бота в Telegram и нажимаете /start
2. Вы пишете боту любое сообщение
3. Бот публикует его в общем чате с пометкой «Аноним»

Никто в чате не узнает, кто отправил сообщение. Ни ваше имя, ни фотография, ни ID не показываются.

---

## Для чего это нужно

- Признаться в чувствах без страха отказа
- Задать неловкий вопрос психологу или врачу
- Сообщить о проблеме начальнику анонимно
- Высказать мнение, которое боишься говорить открыто
- Поучаствовать в обсуждении, если стесняешься

---

## Команды для всех

Напишите боту в личные сообщения:

- /start — начать работу
- /help — показать список команд
- /rules — прочитать правила чата
- /online — узнать, кто из администраторов онлайн

**Просто напишите любое сообщение** — и оно уйдёт в чат анонимно.

---

## Как назначаются администраторы

Первый администратор добавляется командой /admin и своим ID. Дальше админы могут добавлять других админов.

**Команды администраторов:**

- Добавлять и удалять других админов
- Банить и разбанивать нарушителей
- Заглушать (мут) на определённое время
- Выгонять (кик) из чата
- Смотреть статистику и списки

---

## Где хранятся данные

Бот использует простые JSON-файлы:

- admins.json — список администраторов
- banned.json — список забаненных пользователей

Всё хранится на сервере, где запущен бот. Никакой внешней базы данных не требуется.

---

## Требования для работы

Чтобы бот работал в группе:

- Бот должен быть добавлен в группу
- Бот должен иметь права администратора (удалять сообщения, банить, мутить)
- Пользователи должны писать боту в личные сообщения (бот не видит сообщения в группе)

---

## Как запустить своего бота

1. Создайте бота у @BotFather и получите токен
2. Скачайте код бота
3. Вставьте токен в нужное место
4. Запустите бота командой python bot.py
5. Добавьте бота в группу как администратора
6. Назначьте себя админом командой /admin и вашим ID

## Ограничения

- Только текстовые сообщения (фото и видео не поддерживаются)
- Администраторы видят ID нарушителей (нужно доверять админам)
- Не подходит для очень больших групп (более 1000 активных пользователей)
